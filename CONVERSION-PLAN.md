# План доработок лендинга HlobaFlow для роста конверсии

> Документ — рабочий чек-лист улучшений. Опросник из формы убираем полностью.
> Разбито на 4 волны по приоритету (от «без этого нельзя лить трафик»
> до «полировка под A/B-тесты»).

---

## ВОЛНА 1 — Критичное (без этого лиды теряются и слепая воронка)

### 1.1. Упростить форму до базовой

**Файл:** `src/components/RegisterForm.jsx`

- Удалить весь блок `SURVEY` (массив вопросов и весь UI: `fieldset`, `form-question`, `form-options`).
- Удалить state `survey`, функции `setSingle`, `toggleMulti`, проверки опросника в `validate()`.
- Из payload убрать ключ `survey`.
- Оставить **3 поля + чекбокс**: имя, телефон (с кодом страны), email, согласие.
- Удалить блок `form-highlights` сверху формы (опционально — дублирует hero/topbar).
- В `src/styles/components.css` зачистить неиспользуемые стили `.form-question*`, `.form-option*`, `.form-divider` (можно не трогать — мёртвый CSS не мешает).

**Эффект:** ожидаемый прирост сабмитов +30–60%.

---

### 1.2. Надёжная отправка лида + fallback

**Файл:** `src/components/RegisterForm.jsx`

- Сейчас если `WEBHOOK_URL` пустой — заявка уходит в `console.info`. Это **тихий слив лидов**.
- Что делаем:
  - Если webhook не задан в проде → показывать пользователю ошибку «временно недоступно, напишите в Telegram @…».
  - Дублировать каждую заявку **в два места**: основной webhook (n8n/Make/Zapier) + резервный (второй webhook или email через FormSubmit / Web3Forms).
  - На 5xx и таймауты — retry 1 раз через 1.5 сек.

**От тебя нужно:**
- URL основного webhook (n8n/Make).
- URL резервного канала (или согласие что лид дублируется на email).

---

### 1.3. Pixel/GA-события **до** редиректа в Telegram

**Файл:** `src/components/RegisterForm.jsx`

Сейчас после успеха сразу `window.location.href = TELEGRAM_BOT_URL` — события в GA/Pixel улететь не успевают.

Меняем на:
1. Отправить fetch на webhook (как сейчас).
2. Отправить событие конверсии:
   - `window.dataLayer.push({event: 'lead_submit', ...})`
   - `fbq('track', 'Lead')`
   - `gtag('event', 'generate_lead', ...)`
3. Через `navigator.sendBeacon` или `setTimeout(redirect, 200)` — редирект в бот.

## Контрольные метрики после внедрения

После Спринта 1 в GA4 / Meta Events Manager должны появиться события:

| Событие | Где срабатывает | Зачем |
|---|---|---|
| `page_view` | загрузка страницы | базовая воронка |
| `view_section_register` | секция формы попала в viewport | % дошедших до формы |
| `form_field_focus` | фокус в первое поле | % начавших заполнять |
| `form_submit_attempt` | клик по «Зареєструватися» | % дошедших до сабмита |
| `lead_submit` (= Lead в Pixel) | успешный fetch на webhook | финальная конверсия |
| `tg_redirect` | переход в Telegram-бот | проверка что редирект работает |

Это даст полную воронку: **impression → scroll → field focus → submit attempt → lead → tg redirect**.

Без этой воронки любые «улучшения» — пальцем в небо.
